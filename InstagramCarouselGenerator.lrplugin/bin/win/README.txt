ImageMagick Windows Binaries
=============================

This folder should contain the ImageMagick portable binaries for Windows.

Required file:
- magick.exe (ImageMagick 7.x portable executable)

To obtain this file:
1. Go to https://imagemagick.org/script/download.php#windows
2. Download the portable version (e.g., ImageMagick-7.x.x-portable-Q16-x64.zip)
3. Extract the archive
4. Copy 'magick.exe' to this folder

The plugin will automatically use this bundled binary instead of requiring
users to install ImageMagick system-wide.
