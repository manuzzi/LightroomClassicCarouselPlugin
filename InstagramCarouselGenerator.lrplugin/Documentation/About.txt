Instagram Carousel Generator for Adobe Lightroom Classic
============================================================

Version: 1.0.0

ABOUT
-----
The Instagram Carousel Generator plugin helps you create seamless carousel 
posts for Instagram directly from Adobe Lightroom Classic. This plugin 
provides export presets and tools optimized for Instagram's carousel format.

FEATURES
--------
- Export photos optimized for Instagram carousel format (1080x1080px by default)
- Seamless carousel mode for creating connected panoramic posts
- Customizable export dimensions
- Support for multiple image formats (JPEG, TIFF, PNG)

INSTALLATION
------------
1. Download the plugin
2. Copy the InstagramCarouselGenerator.lrplugin folder to:
   - macOS: ~/Library/Application Support/Adobe/Lightroom Classic/Plugins/
   - Windows: %APPDATA%\Adobe\Lightroom Classic\Plugins\
3. Open Lightroom Classic
4. Go to File > Plug-in Manager
5. Click "Add" and select the InstagramCarouselGenerator.lrplugin folder
6. Click "Done"

USAGE
-----
1. Select photos in Lightroom Classic Library module
2. Go to File > Export
3. Select "Instagram Carousel" from the export presets
4. Configure your carousel settings
5. Click "Export"
