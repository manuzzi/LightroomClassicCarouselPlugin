Instagram Carousel Generator for Adobe Lightroom Classic
============================================================

ABOUT
-----
The Instagram Carousel Generator plugin helps you create seamless carousel 
posts for Instagram directly from Adobe Lightroom Classic. This plugin 
provides export presets and tools optimized for Instagram's carousel format.

FEATURES
--------
- Export photos optimized for Instagram carousel format with multiple aspect ratios
- Aspect ratio presets: 4:5 (Portrait), 1:1 (Square), 5:4 (Landscape), 16:9 (Wide), 9:16 (Vertical), and Custom
- Seamless carousel mode for splitting panoramic photos into edge-to-edge tiles
- Smart overflow handling with two options:
  * Add bands with optional customizable frames
  * Crop to fit perfectly
- Customizable styling: background color (RGB values), frame color (RGB values), and frame width
- Support for multiple image formats (JPEG, TIFF, PNG)

REQUIREMENTS
------------
For seamless carousel mode (image splitting), ImageMagick must be installed:
- macOS: brew install imagemagick
- Windows: Download from https://imagemagick.org

Without ImageMagick, photos will be exported as single images.
